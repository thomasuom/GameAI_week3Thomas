# Escape Lab 2D — Level 3

Unity 6 project with the five **Build Game Features** tasks completed:

- Collection, damage, unlock and win sounds.
- Heart icons and a collection progress bar.
- P to pause/resume the timer, movement and audio.
- Easy, Medium and Hard settings in the pause/end menu.
- A saved best score shown during and between rounds.

The existing laptop branch's sprint, special cells, health/poison pickups,
maze and hunters are retained. The saved scene is Assets/Scenes/EscapeLab2D.unity.

**Start here:** [LEVEL3_GUIDE.md](LEVEL3_GUIDE.md) explains opening the project,
controls, difficulty rules, the code and the Unity Play-mode checklist.

The project uses the built-in audio and IMGUI modules. No paid Unity AI credits,
external UI package, runtime level generator or manual sound assignment is needed.

Automated validation: 19 C# checks using test-only Unity stand-ins, plus saved
scene/asset-reference checks. A live Unity Editor was unavailable, so actual
Unity compilation and Play-mode testing remain to be done locally.

The original STUDENT_GUIDE.md and TEACHER_NOTES.md describe the Week 1 foundation.
